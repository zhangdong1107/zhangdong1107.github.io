Quaternion SVD using complex MATLAB matrices

This package computes a singular value decomposition of a quaternion matrix through its complex representation. It uses built-in MATLAB functions and requires no quaternion class or third-party toolbox. The download includes the algorithm, a self-contained example, eight numerical checks, and an English README.

Quick start

  1. Download and extract the ZIP package.
  2. In MATLAB, open the extracted folder containing the .m files.
  3. Run the demo and numerical checks:
demo_qsvd
test_qsvd

Validated with MATLAB R2025a on Windows. All eight bundled checks passed. The example's relative reconstruction error was approximately 1.14 × 10−15. Other MATLAB releases and GNU Octave have not been tested for this distribution.

Use your own quaternion matrix

For A = A0 + A1 i + A2 j + A3 k, supply four real matrices of the same size. MATLAB's 1i below denotes the ordinary complex unit.

B1 = A0 + 1i*A1;
B2 = A2 + 1i*A3;
AC = quaternion_to_complex(B1, B2);
[m, n] = size(A0);
[UC, EC, VC] = qsvd_complex(AC, m, n);
% Reconstruct the complex representation:
AC_reconstructed = UC * EC * VC';

See the README for matrix dimensions, tolerance, repeated singular values, zero matrices, and troubleshooting.
