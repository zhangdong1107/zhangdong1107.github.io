# Dong Zhang — Academic Homepage

Public website: https://zhangdong1107.github.io/

This is a static English academic homepage hosted with GitHub Pages.

- `index.html`: profile, research, publications, and contact details.
- `styles.css`: responsive layout.
- `images/`: supplied portrait.
- `downloads/`: documented MATLAB package.
- QSVD source: https://github.com/zhangdong1107/QSVD

Edit the HTML/CSS and push to `main` to update the website. Update the footer date and `sitemap.xml` when content changes. No external fonts or JavaScript services are needed to read the page.
